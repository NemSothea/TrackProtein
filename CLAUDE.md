# TrackProtein — iOS Protein Tracker

"Track protein. Nothing else." Fast, private, protein-only tracking app. Full product plan, phases, and timeline: see `PLAN.md`. Screen designs & design system: `docs/design/`.

**Task tracking: `MEMORY.md` is the single source of truth for progress.** Read it at the start of work; tick items and bump "Last updated" whenever a task completes. Launch strategy: build ALL phases first, deploy once at the end — don't push toward TestFlight/submission early.

## Stack
- SwiftUI + MVVM (`@Observable` ViewModels), iOS 17+, Swift 5 mode
- SwiftData for persistence (CloudKit sync planned, not yet enabled)
- XcodeGen — `project.yml` is the source of truth; **never edit `TrackProtein.xcodeproj` directly** (it's gitignored). After adding/removing files run `xcodegen generate`.

## Build & run
```bash
xcodegen generate
xcodebuild -project TrackProtein.xcodeproj -scheme TrackProtein \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' build
```
These also run automatically via skills/agents (just ask in plain English, or invoke by name):
- Skills — `trackprotein-run-sim` (build/run/verify in Simulator), `trackprotein-run-device` (build/run on iPhone), plus `trackprotein-feature`, `trackprotein-ml`, `trackprotein-proxy`.
- Agents — `trackprotein-auditor` (read-only audit vs PLAN.md), `trackprotein-reviewer` (read-only Swift code review).

## Structure
```
TrackProtein/
├── App/            # TrackProteinApp, RootView, MainTabView
├── Core/
│   ├── Models/     # SwiftData @Model: UserProfile, ProteinEntry, FavoriteFood (+ GoalType, LogSource enums)
│   ├── Services/   # GoalCalculator, StreakCalculator (pure, testable)
│   └── Extensions/ # Date+, Color+Theme (proteinOrange / proteinDeep)
├── Features/       # One folder per feature: View + ViewModel
│   ├── Onboarding/ # 3 steps: welcome → weight+goal → target
│   ├── Home/       # Progress ring, favorites chips, today log
│   ├── LogEntry/   # QuickAddView — add AND edit (pass entry: to edit, presetDate: for past days)
│   ├── History/    # Day summaries, streak, DayDetailView
│   └── Settings/   # Profile/target editing via @Bindable
└── Resources/      # Assets.xcassets
TrackProteinWidgets/ # WidgetKit extension (shares TrackProtein/Core sources + App Group store)
Configs/             # XcodeGen-generated Info.plists & entitlements (do not hand-edit)
```
- Data store lives in App Group `group.com.sothea.trackprotein` via `SharedStore.makeContainer()` — app and widgets read the same SwiftData store.
- **Every data mutation must call `WidgetRefresher.refresh()`** so widgets stay current.
- Deep link `trackprotein://add` (from widget tap) → MainTabView routes to Today + opens QuickAdd.

## Conventions
- ViewModels: `@Observable final class`, no `ObservableObject`. Pass `ModelContext` into VM methods as a parameter (keeps VMs testable) — don't store it.
- Views use `@Query` for SwiftData lists; filter/group in the ViewModel from the queried array (in-memory is fine at this scale).
- Enums stored in SwiftData models as `<name>Raw: String` + computed typed property (see `UserProfile.goalType`).
- Grams displayed as `Int(value.rounded())` + `"g"`. Targets rounded to nearest 5 g.
- Brand color: `Color.proteinOrange` (defined in Color+Theme); goal-met state uses green.
- No third-party dependencies in Phase 1. Don't add packages without asking.
